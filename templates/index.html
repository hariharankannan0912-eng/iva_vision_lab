OBJECT LOCALIZATION

Template Matching

Find where a small reference image appears inside a larger scene.

BASE INSTALL
How it works

OpenCV slides the template across the scene and scores each location using normalized correlation. The best-scoring position is marked with a rectangle.

CLASSICAL FACE DETECTION

Viola–Jones

Detect frontal faces using a Haar-cascade classifier.

BASE INSTALL
How it works

The Viola–Jones framework popularized integral images, Haar-like features, AdaBoost feature selection, and a cascade of classifiers for fast face detection.

DEEP LEARNING · FACE VERIFICATION

DeepFace

Compare two portraits with a pretrained face-recognition model.

OPTIONAL MODEL
How it works

DeepFace provides a unified interface to face-recognition models and verification pipelines. This demo uses its Facenet512 model and OpenCV face detector.

FACE EMBEDDINGS

FaceNet

Turn faces into vectors and compare their cosine similarity.

OPTIONAL MODEL
How it works

FaceNet maps aligned face crops into an embedding space. Images of the same person are expected to have embeddings closer together than unrelated faces, although thresholds depend on the model and data.
